## 🆘 Quick Troubleshooting

| Problem | Fix |
|---------|-----|
| "Port 5000 in use" | `netstat -ano \| findstr :5000` then kill it |
| "ModuleNotFoundError" | `pip install -r requirements.txt` |
| "Slow comparison" | Use smaller images or disable SIFT |
| "Memory error" | Use fewer workers or reduce image size |
| "Upload fails" | Check file size (<10MB) and format |

**More help**: See `SETUP.md` troubleshooting section
